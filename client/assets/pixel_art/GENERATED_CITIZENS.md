# Citizen roster v1

`citizen_roster_v1.png` was generated with the built-in image generation tool
for the Aitizen Realm citizen chooser.

## Final prompt

Create eight distinct selectable citizen characters matching the existing cozy,
polished chibi fantasy style. Arrange them in an exact four-column by two-row
grid with one centered full-body character per equal cell, consistent scale and
baseline, facing three-quarter right. The roster contains eight visually
distinct citizens using teal, rust, moss, indigo, burgundy, ochre, sky-blue,
and violet palettes. Use shared cream trim and brown leather equipment, crisp
outlines, transparent padding, no text, no scene, no overlap, and no watermark.

The image is 1536 × 1024 with eight 384 × 512 regions. The transparent atlas is
retained as concept artwork. Runtime citizens and picker previews now use the
existing action atlas with consistent per-appearance colour modulation. Walking
and tool actions use their original source frame sequences; sleep uses the
12-frame sleep atlas. These are shared animation silhouettes with colour
variants, not eight independently authored animation sets. The previous
single-image squash animation was removed because it lost the actual walking
and work poses.
