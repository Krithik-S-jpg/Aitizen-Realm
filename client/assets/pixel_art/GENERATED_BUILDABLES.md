# Buildables atlas v1

`buildables_atlas_v1.png` was generated with the built-in image generation
tool for Aitizen Realm's world renderer.

## Final prompt

Create a transparent, production-ready 4 x 2 isometric pixel-art atlas with
exactly eight buildables in row-major order: timber shelter cabin, canvas tent,
storage shed, stone-ring campfire, carpenter workbench, masonry well, cultivated
farm plot, and wooden fence. Keep one centered object in each equal cell with a
consistent baseline, scale and upper-left daylight. Use believable wood grain,
stonework, cloth seams, roof shingles, tools and crops. No text, labels, borders,
people, animals, UI, watermark, scenery, overlap or cropped objects.

The image is 1774 x 887 with transparent alpha. The renderer divides it into
four columns and two rows at runtime, uses the assets for completed structures,
and reveals them progressively behind physical foundations, delivered material
piles and scaffolding while construction is underway.
