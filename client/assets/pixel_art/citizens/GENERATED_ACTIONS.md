# Citizen action artwork

Generated with the built-in image-generation tool. Source PNGs are preserved with alpha; the bake tool only produces frame-coordinate metadata. Runtime uses eight identity-specific sheets plus Rowan's gathering supplement. Each action has six source poses, sampled at 24 Hz; this is not 24 unique source drawings per action.

Saved assets: `client/assets/pixel_art/citizens/{scout,builder,herbalist,scholar,cook,miner,fisher,artisan}_actions_v1.png` and `cook_gather_v1.png`. Source coordinates: `client/config/citizen_actions.json`. Regenerate coordinates with `client/tools/BakeCitizenRegions.gd` before validating with `PreviewCitizenCatalog.gd`.
